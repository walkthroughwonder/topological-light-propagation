How It Works

Path Weights → Amplitudes

Each state at step N is weighted by the number of distinct evolution paths leading to it. Normalized weights correspond to |ψ|² — the squared magnitudes of quantum amplitudes. The interference pattern emerges from the branching structure.

Branchial Space = Hilbert Space

States at a given step, connected by shared ancestry, form the branchial graph. Its geometry maps onto the projective Hilbert space of the system. Single-slit → 1D, double-slit → 2D, triple-slit → 3D.

Completion → Interference

A Knuth-Bendix completion forces causal invariance. Spacelike-separated paths (isomorphic, phase ≈ 0) merge constructively — weights add. Branchlike-separated paths (non-intersecting, phase ≈ π) interfere destructively — weights cancel.
